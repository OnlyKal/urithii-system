# Documents éditoriaux d'URITHI

Livrables éditoriaux prévus par le cahier des charges (§92). Ils décrivent **comment** collecter, traiter, valider, publier et conserver le patrimoine documenté sur URITHI.

> **Statut : versions de travail.** Les formulaires juridiques et les politiques doivent être adaptés et vérifiés par une personne compétente en droit congolais avant toute utilisation réelle (§92). Les guides seront améliorés grâce aux enseignements du pilote Havu (§77).
