# Guide de transcription

La transcription met par écrit, **dans la langue d'origine**, ce qui est dit dans un enregistrement audio ou vidéo (§29).

## Règles
1. **Fidélité** : on écrit ce qui est dit, sans résumer, corriger ni embellir.
2. **Langue d'origine** : on transcrit dans la langue parlée. La traduction est un travail séparé.
3. **Repères temporels** : indiquez le minutage au début de chaque passage, par exemple `[00:03:15]`, pour retrouver le passage dans l'enregistrement.
4. **Locuteurs** : identifiez qui parle, par exemple `NARRATRICE :` ou `COLLECTEUR :`, selon le mode d'attribution autorisé.
5. **Passages incertains** : `[inaudible 00:04:10]` ou `[mot incertain : …?]`. Ne devinez pas.
6. **Bruits et événements** : entre crochets, par exemple `[chant collectif]` ou `[rires]`.
7. **Passages restreints** : si la personne a demandé qu'une partie ne soit pas diffusée, signalez-le par `[passage restreint — ne pas publier]`, puis informez l'éditeur.

## Dans URITHI
1. Depuis le média ou la fiche : **Ajouter une transcription ou une traduction**.
2. Type « Transcription », langue du texte, méthode :
   - **Manuelle** : vous transcrivez vous-même.
   - **Outil automatique** : texte produit par un logiciel. Il reste marqué « non vérifié » jusqu'au contrôle d'une personne compétente.
3. Chaque correction crée une **nouvelle version** avec un motif. Les versions précédentes restent consultables.
4. La **vérification** doit être faite par une autre personne que l'auteur de la dernière version, compétente dans la langue concernée. Toute nouvelle révision annule la vérification précédente.
5. L'affichage public d'une transcription est décidé par un éditeur, une fois le texte vérifié et autorisé.
